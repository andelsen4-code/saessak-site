# 사이트 설계도(PRD) — 새싹 공방

작성일: 2026-11-20 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
새싹 공방의 원데이 클래스를 소개하고, 주말 수업 예약 문의를 받는 사이트.

## 2. 손님
- 누가: 주말에 할 취미를 찾는 직장인
- 어디서 알고 오나: 인스타그램 (프로필 링크로 들어옴)

## 3. 손님이 궁금한 것 (연락하기 전에)
1. 가격
2. 주말 수업 시간
3. 초보도 가능한지

## 4. 믿게 할 증거 (실제로 있는 것만)
- 수업·작품 사진: 있음 (사진 파일 받아서 넣기)
- 강사 경력·자격: 있음 (사용자가 준 내용 그대로 넣기. 지금은 (미정))
- 후기: 실제 수강 후기 있음 (사용자가 준 원문만 넣기. 지어내지 않음)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 주말 클래스 예약 문의
- 누르면: 문의 폼

## 6. 페이지 구성 (위에서 아래로, 한 페이지)
1. 첫 화면: 한 문장 + 「주말 클래스 예약 문의」 버튼
2. 수업 안내: 가격 · 주말 수업 시간 · 초보 가능 여부 (손님이 궁금한 세 가지)
3. 수업·작품 사진
4. 강사 소개 (경력·자격)
5. 수강 후기 (실제 후기)
6. 문의 폼

## 7. 문의 폼에서 받을 것
- 이름, 연락처
- 원하는 날짜
- 개인정보 수집·이용 동의 (필수)

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 가격: (미정)
- 시간: (미정)
- 위치: (미정)
- 연락 방법: (미정)

## 9. 이번에 넣지 않을 것
- 회원가입·로그인
- 결제
- 사진 올리기
- 알림 메일

## 10. 첫 화면 한 문장 후보
1. 주말 하루, 손으로 만드는 나만의 작품 — 새싹 공방 원데이 클래스
2. 처음이어도 괜찮아요. 주말 오후를 채우는 새싹 공방 원데이 클래스
3. 바쁜 한 주 끝, 주말엔 새싹 공방에서 천천히 만들어 보세요

## 11. 다음에 할 것
- 가격·주말 수업 시간·위치·연락 방법 확정해서 8번 채우기
- 강사 경력·자격, 실제 후기 원문, 사진 파일 받기
- 회원가입·결제·사진 올리기·알림 메일 (필요해지면)

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 고급스러운 · 참고 디자인: 없음 — 클로드가 정함
- 문의 저장: 예 → Supabase(leaderpl-admin 스킬) + /admin
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. 문의 폼 → Supabase 저장 → /admin 관리자 페이지까지 만든다
4. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 관리자 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력
